# 🏥 Sistema de Encaminhamento Médico

Sistema de triagem automática que encaminha pacientes de acordo com os sintomas.

## Como funciona
- Febre + Tosse → Medicina Geral
- Dor no peito + Falta de ar → Urgência / Cardiologia
- Sangramento vaginal → Ginecologia
- Trauma / Ferida → Cirurgia

## Tecnologias
PHP + MySQL + XAMPP

## Como rodar
1. Copiar para C:\xampp\htdocs\
2. Iniciar Apache no XAMPP
3. Abrir http://localhost/sistema-encaminhamento/
